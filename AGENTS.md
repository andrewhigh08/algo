# AGENTS.md

Инструкции для ИИ-агентов (Claude Code, Copilot, Codex и других), которые работают с этим репозиторием.

## Главное

- Это личный репозиторий для тренировки алгоритмов на Go. Решения владелец пишет сам: **не решай задачи и не дописывай решения, если об этом прямо не попросили**. Новая задача добавляется как условие и заготовка без решения.
- Всё, что читает человек (условия, разборы, README, комментарии в коде), пишется на русском. Названия задач, идентификаторы и значения в примерах остаются в оригинале.
- Логику существующих решений не меняй без просьбы. Заметил ошибку — сообщи о ней, но не исправляй.

## Структура

```text
README.md                                    сводный прогресс по платформам
leetcode/README.md                           оглавление по темам NeetCode 150 и прогресс
leetcode/<easy|medium|hard>/<номер>. <название>/
    README.md                                условие на русском и разбор решения
    main.go                                  решение или заготовка
codeforces/README.md                         таблица задач
codeforces/<контест><буква>. <название>/main.go
codewars/<ранг>/<название>/                  README.md + main.go
yandex/<задача>/                             README.md + main.go + input.txt / output.txt
```

## Сборка и проверки

`go.mod` нет намеренно: в именах папок есть пробелы, а такой путь не может быть import path. Каждая задача — отдельная программа в `package main`, поэтому файл всегда передаётся явно. Из папки задачи:

```bash
gofmt -l main.go   # ничего не выводит
go vet main.go
go run main.go
```

Для всего репозитория команда `gofmt -l .` из корня ничего не выводит.

## LeetCode

### Папка

`leetcode/<сложность>/<номер>. <название>/`:

- сложность — как на LeetCode: `easy`, `medium` или `hard`;
- номер — номер задачи на LeetCode, в том числе у премиум-задач (не номер LintCode);
- название — точно как на LeetCode: `50. Pow(x, n)`, `167. Two Sum II - Input Array Is Sorted`;
- описание лежит только в `README.md` — отдельные файлы вида `1. Two Sum.md` не создаются.

Образцы, на которые надо равняться:

| Что | Папка |
|---|---|
| решённая задача | `leetcode/easy/1. Two Sum/` |
| заготовка с деревом | `leetcode/easy/104. Maximum Depth of Binary Tree/` |
| заготовка со связным списком | `leetcode/easy/206. Reverse Linked List/` |
| задача на проектирование класса | `leetcode/medium/146. LRU Cache/` |
| премиум-задача | `leetcode/easy/252. Meeting Rooms/` |

### README.md

```markdown
# <номер>. <название>

**<название по-русски>** · <🟢 Easy | 🟡 Medium | 🔴 Hard> · <тема> · [LeetCode](https://leetcode.com/problems/<slug>/description/)

## Условие
## Примеры
## Ограничения
## Дополнительный вопрос   ← только если на LeetCode есть Follow-up
## Решение                 ← только у решённых задач
## Заметки                 ← только у нерешённых, если есть свои заметки
```

- Заголовок совпадает с именем папки. В русском названии с заглавной буквы пишется только первое слово.
- Тема — раздел NeetCode 150: `Arrays & Hashing`, `Two Pointers`, `Sliding Window`, `Stack`, `Binary Search`, `Linked List`, `Trees`, `Tries`, `Heap / Priority Queue`, `Backtracking`, `Graphs`, `Advanced Graphs`, `1-D Dynamic Programming`, `2-D Dynamic Programming`, `Greedy`, `Intervals`, `Math & Geometry`, `Bit Manipulation`. Задаче вне списка ставится ближайшая тема, а в оглавлении она попадает в раздел «Дополнительные задачи».
- Премиум-задача: `[LeetCode 🔒](<ссылка>) · [LintCode <номер>](https://www.lintcode.com/problem/<номер>/)`.
- Условие — точный перевод официального. Код, переменные и выражения — в обратных кавычках; в тексте — тире ` — ` и кавычки «»; списки через `- `; без HTML и горизонтальных линий.
- Пример:

  ````markdown
  **Пример 1:**

  ![Пример 1](https://assets.leetcode.com/uploads/...)

  ```text
  Input: nums = [2,7,11,15], target = 9
  Output: [0,1]

  ```
  ````

  Картинка — только если она есть в примере на LeetCode. Значения `Input` и `Output` копируются с LeetCode символ в символ, количество примеров совпадает с оригиналом.
- Ограничения — по одному на строку, в обратных кавычках, с `≤`, `≥` и надстрочными индексами: `` - `1 ≤ nums.length ≤ 10⁴` ``, `` - `-2³¹ ≤ x ≤ 2³¹ - 1` ``.
- Решение:

  ```markdown
  ## Решение

  Код — [main.go](main.go). <1–3 предложения об идее решения из main.go>

  - Время: `O(n)`
  - Память: `O(n)`
  ```

  Ниже — диаграммы mermaid и ссылки на файлы `.excalidraw` из папки задачи, если они есть.

- Первая строка — ссылка на задачу. У премиум-задач — `// <ссылка> (Premium)`, а второй строкой — ссылка на LintCode.
- Сигнатура — ровно как в Go-шаблоне LeetCode: те же имена, типы и получатель `this` у методов.
- `main()` вызывает все примеры из условия, а в комментарии к каждому — правильный ответ в том виде, в каком его напечатает `fmt.Println`.
- `// TODO: решить` — признак нерешённой задачи. В задачах на класс он стоит внутри структуры, а методы возвращают нулевые значения.
- Типы `ListNode` и `TreeNode`, помощники `newList`, `newTree` и `String()` идут после строки `// --- Вспомогательный код для запуска примеров ---`. Их код копируется из образцов.

### Когда задача решена

1. В `main.go` вместо `// TODO: решить` пишется решение, над функцией — комментарий со сложностью по времени и памяти.
2. В `README.md` добавляется раздел `## Решение` (см. выше).
3. В `leetcode/README.md` знак `⬜` меняется на `[✅](<путь к папке>/main.go)` и пересчитывается прогресс: в шапке, в таблице тем и в корневом `README.md`.

В ссылках оглавлений пробелы и спецсимволы кодируются: `easy/1.%20Two%20Sum/`, `medium/50.%20Pow%28x%2C%20n%29/`.

## Codeforces

- Папка `codeforces/<контест><буква>. <название>/main.go`. Символы `<>:"/\|?*` и точки в конце названия убираются.
- Первая строка — ссылка: `// https://codeforces.com/problemset/problem/<контест>/<буква>`.
- Решение читает stdin и печатает ответ в stdout.
- Новой задаче нужна строка в таблице `codeforces/README.md` (рейтинг и теги — со страницы задачи) и обновлённый счётчик в корневом `README.md`.

## Codewars и Яндекс

- Codewars: `codewars/<ранг>/<название>/` — `README.md` в формате LeetCode (в шапке ранг и ссылка на кату, например `**Сумма интервалов** · 4 kyu · [Codewars](<ссылка>)`) и `main.go`. Новая ката добавляется в таблицу `codewars/README.md`.
- Яндекс: `yandex/<задача>/` — `README.md`, `main.go`, `input.txt` и `output.txt`. В шапке README — источник и ссылка на условие (`**Яндекс «Тренировки по алгоритмам 5.0», занятие 1** · [Условие](<ссылка>)`), разделы — `## Условие`, `## Формат ввода`, `## Формат вывода`, `## Примеры`, `## Решение`. Программа читает `yandex/<задача>/input.txt`, поэтому запускается из корня: `go run yandex/<задача>/main.go`. Новая задача добавляется в таблицу `yandex/README.md`.

## Git

- Коммиты идут прямо в `main`, без веток и PR.
- Коммит с задачей называется `<номер>. <название>`, например `739. Daily Temperatures`. Остальные сообщения — коротко, по-английски.
- Никаких `Co-Authored-By` и других строк о соавторстве.
