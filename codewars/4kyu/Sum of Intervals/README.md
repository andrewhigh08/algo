# Sum of Intervals

**Сумма интервалов** · 4 kyu · [Codewars](https://www.codewars.com/kata/52b7ed099cdc285c300001cd)

## Условие

Напишите функцию `sumIntervals`/`sum_intervals` (в Go — `SumOfIntervals`), которая принимает массив интервалов и возвращает сумму длин всех интервалов. Перекрывающиеся интервалы нужно учитывать только один раз.

**Интервалы.** Интервал задаётся парой целых чисел в виде массива. Первое значение интервала всегда меньше второго. Пример: `[1, 5]` — интервал от `1` до `5`, его длина равна `4`.

**Перекрывающиеся интервалы.** Возьмём список с перекрывающимися интервалами `[[1, 4], [7, 10], [3, 5]]`. Сумма длин этих интервалов равна `7`: поскольку `[1, 4]` и `[3, 5]` перекрываются, их можно считать одним интервалом `[1, 5]` длины `4`.

## Примеры

**Пример 1:**

```text
Input: intervals = [[1, 2], [6, 10], [11, 15]]
Output: 9
```

**Пример 2:**

```text
Input: intervals = [[1, 4], [7, 10], [3, 5]]
Output: 7
```

**Пример 3:**

```text
Input: intervals = [[1, 5], [10, 20], [1, 6], [16, 19], [5, 11]]
Output: 19
```

**Пример 4:**

```text
Input: intervals = [[0, 20], [-100000000, 10], [30, 40]]
Output: 100000030
```

## Ограничения

- Алгоритм должен справляться с большими интервалами: все интервалы в тестах — подмножества отрезка `[-10⁹, 10⁹]`.

## Решение

Код — [main.go](main.go). `SumOfIntervals` сортирует интервалы по левому концу (на месте, входной срез меняется) и проходит по ним один раз, храня в `point` правую границу уже учтённой части: интервал, который кончается не правее `point`, пропускается, пересекающийся добавляет только выступающий кусок `intervals[i][r] - point`, а лежащий правее — всю свою длину. `SumOfIntervals_` — более ранняя и более медленная попытка без сортировки: `check` ищет среди уже добавленных интервалов пересекающийся, `f` расширяет его, и проходы повторяются, пока слияния не прекратятся.

- Время: `O(n log n)` — из-за сортировки
- Память: `O(1)` дополнительной (сортировка на месте)
