# Codeforces

Решения задач с [Codeforces](https://codeforces.com/problemset) на Go: **66 задач**, в основном A и B из Div. 2 (рейтинг 800–1500).

Каждая задача лежит в отдельной папке `<контест><буква>. <название>/main.go`. Решение читает входные данные из stdin и печатает ответ в stdout:

```bash
cd "codeforces/1A. Theatre Square"
echo "6 6 4" | go run main.go   # 4
```
