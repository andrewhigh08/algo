# Яндекс

Задачи с контестов Яндекса на Go.

Каждая задача — папка с условием в `README.md`, решением в `main.go` и файлами `input.txt` / `output.txt`. Пути к ним заданы от корня репозитория, поэтому программу запускают из корня:

```bash
go run yandex/A1/main.go   # читает yandex/A1/input.txt, пишет ответ в yandex/A1/output.txt
```
