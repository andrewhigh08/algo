# 543. Diameter of Binary Tree

**Диаметр бинарного дерева** · 🟢 Easy · Trees · [LeetCode](https://leetcode.com/problems/diameter-of-binary-tree/description/)

## Условие

Дан корень бинарного дерева `root`. Верните *длину **диаметра** дерева*.

**Диаметр** бинарного дерева — это **длина** самого длинного пути между любыми двумя узлами в дереве. Этот путь может проходить или не проходить через `root`.

**Длина** пути между двумя узлами — это количество рёбер между ними.

## Примеры

**Пример 1:**

![Пример 1](https://assets.leetcode.com/uploads/2021/03/06/diamtree.jpg)

```text
Input: root = [1,2,3,4,5]
Output: 3
Explanation: 3 — это длина пути [4,2,1,3] или [5,2,1,3].
```

**Пример 2:**

```text
Input: root = [1,2]
Output: 1
```

## Ограничения

- Количество узлов в дереве — в диапазоне `[1, 10⁴]`.
- `-100 ≤ Node.val ≤ 100`
