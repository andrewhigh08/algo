# 9. Palindrome Number

**Число-палиндром** · 🟢 Easy · Math & Geometry · [LeetCode](https://leetcode.com/problems/palindrome-number/description/)

## Условие

Дано целое число `x`. Верните `true`, если `x` является **палиндромом**, и `false` в противном случае.

## Примеры

**Пример 1:**

```text
Input: x = 121
Output: true
Explanation: 121 читается как 121 и слева направо, и справа налево.
```

**Пример 2:**

```text
Input: x = -121
Output: false
Explanation: слева направо читается -121, а справа налево — 121-. Следовательно, это не палиндром.
```

**Пример 3:**

```text
Input: x = 10
Output: false
Explanation: справа налево читается 01. Следовательно, это не палиндром.
```

## Ограничения

- `-2³¹ ≤ x ≤ 2³¹ - 1`

## Дополнительный вопрос

Сможете ли вы решить задачу, не преобразуя число в строку?

## Решение

Код — [main.go](main.go). Решение без преобразования в строку: отрицательные числа сразу отбрасываются, затем находится делитель `div` — наибольшая степень десяти, не превосходящая `x`. Крайняя левая (`x / div`) и крайняя правая (`x % 10`) цифры сравниваются, после чего обе отрезаются (`x = (x % div) / 10`, `div /= 100`), и проверка сдвигается к центру числа.

- Время: `O(log₁₀(x))`
- Память: `O(1)`
