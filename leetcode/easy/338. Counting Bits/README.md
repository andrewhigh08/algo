# 338. Counting Bits

**Подсчет битов** · 🟢 Easy · Bit Manipulation · [LeetCode](https://leetcode.com/problems/counting-bits/description/)

## Условие

Дано целое число `n`. Верните *массив `ans` длины `n + 1`, такой, что для каждого `i` (`0 ≤ i ≤ n`) `ans[i]` равно **количеству единиц** в двоичном представлении числа `i`*.

Не используйте для решения встроенные функции (например, `__builtin_popcount` в C++).

## Примеры

**Пример 1:**

```text
Input: n = 2
Output: [0,1,1]
Explanation:
0 --> 0
1 --> 1
2 --> 10
```

**Пример 2:**

```text
Input: n = 5
Output: [0,1,1,2,1,2]
Explanation:
0 --> 0
1 --> 1
2 --> 10
3 --> 11
4 --> 100
5 --> 101
```

## Ограничения

- `0 ≤ n ≤ 10⁵`

## Дополнительный вопрос

Очень легко придумать решение со временем выполнения `O(n log n)`. Сможете ли вы решить задачу за линейное время `O(n)` и, возможно, за один проход?
