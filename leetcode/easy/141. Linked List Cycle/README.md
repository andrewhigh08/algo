# 141. Linked List Cycle

**Цикл в связном списке** · 🟢 Easy · Linked List · [LeetCode](https://leetcode.com/problems/linked-list-cycle/description/)

## Условие

Дана голова `head` связного списка. Определите, есть ли в связном списке цикл.

В связном списке есть цикл, если в нём есть узел, до которого можно снова добраться, непрерывно следуя по указателям `next`. Внутри тестирующей системы `pos` обозначает индекс узла, на который указывает указатель `next` хвоста. **Обратите внимание, что `pos` не передаётся как параметр.**

Верните `true`, *если в связном списке есть цикл*. В противном случае верните `false`.

## Примеры

**Пример 1:**

![Пример 1](https://assets.leetcode.com/uploads/2018/12/07/circularlinkedlist.png)

```text
Input: head = [3,2,0,-4], pos = 1
Output: true
Explanation: в связном списке есть цикл: хвост соединяется с 1-м узлом (нумерация с нуля).
```

**Пример 2:**

![Пример 2](https://assets.leetcode.com/uploads/2018/12/07/circularlinkedlist_test2.png)

```text
Input: head = [1,2], pos = 0
Output: true
Explanation: в связном списке есть цикл: хвост соединяется с 0-м узлом.
```

**Пример 3:**

![Пример 3](https://assets.leetcode.com/uploads/2018/12/07/circularlinkedlist_test3.png)

```text
Input: head = [1], pos = -1
Output: false
Explanation: в связном списке нет цикла.
```

## Ограничения

- Количество узлов в списке — в диапазоне `[0, 10⁴]`.
- `-10⁵ ≤ Node.val ≤ 10⁵`
- `pos` равен `-1` или является **допустимым индексом** в связном списке.
