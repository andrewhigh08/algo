# 703. Kth Largest Element in a Stream

**K-й по величине элемент в потоке** · 🟢 Easy · Heap / Priority Queue · [LeetCode](https://leetcode.com/problems/kth-largest-element-in-a-stream/description/)

## Условие

Вы работаете в приёмной комиссии университета, и вам нужно в реальном времени отслеживать `k`-й по величине результат теста среди абитуриентов. Это помогает динамически определять проходные баллы для собеседований и зачисления по мере того, как новые абитуриенты присылают свои результаты.

Вам поручено реализовать класс, который для заданного целого числа `k` поддерживает поток результатов тестов и непрерывно возвращает `k`-й по величине результат **после** добавления нового. Точнее, мы ищем `k`-й по величине балл в отсортированном списке всех баллов.

Реализуйте класс `KthLargest`:

- `KthLargest(int k, int[] nums)` — инициализирует объект целым числом `k` и потоком результатов тестов `nums`.
- `int add(int val)` — добавляет в поток новый результат теста `val` и возвращает элемент, который является `k`-м по величине среди всех результатов на данный момент.

## Примеры

**Пример 1:**

```text
Input
["KthLargest", "add", "add", "add", "add", "add"]
[[3, [4, 5, 8, 2]], [3], [5], [10], [9], [4]]
Output
[null, 4, 5, 5, 8, 8]

Explanation
KthLargest kthLargest = new KthLargest(3, [4, 5, 8, 2]);
kthLargest.add(3);  // возвращает 4
kthLargest.add(5);  // возвращает 5
kthLargest.add(10); // возвращает 5
kthLargest.add(9);  // возвращает 8
kthLargest.add(4);  // возвращает 8
```

**Пример 2:**

```text
Input
["KthLargest", "add", "add", "add", "add"]
[[4, [7, 7, 7, 7, 8, 3]], [2], [10], [9], [9]]
Output
[null, 7, 7, 7, 8]

Explanation
KthLargest kthLargest = new KthLargest(4, [7, 7, 7, 7, 8, 3]);
kthLargest.add(2);  // возвращает 7
kthLargest.add(10); // возвращает 7
kthLargest.add(9);  // возвращает 7
kthLargest.add(9);  // возвращает 8
```

## Ограничения

- `0 ≤ nums.length ≤ 10⁴`
- `1 ≤ k ≤ nums.length + 1`
- `-10⁴ ≤ nums[i] ≤ 10⁴`
- `-10⁴ ≤ val ≤ 10⁴`
- Будет сделано не более `10⁴` вызовов `add`.
