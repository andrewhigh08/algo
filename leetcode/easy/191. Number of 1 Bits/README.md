# 191. Number of 1 Bits

**Количество единичных битов** · 🟢 Easy · Bit Manipulation · [LeetCode](https://leetcode.com/problems/number-of-1-bits/description/)

## Условие

Дано положительное целое число `n`. Напишите функцию, которая возвращает количество установленных битов в его двоичном представлении (эта величина также известна как [вес Хэмминга](https://en.wikipedia.org/wiki/Hamming_weight)).

*Установленный бит* — это бит двоичного представления числа, равный `1`.

## Примеры

**Пример 1:**

```text
Input: n = 11
Output: 3
Explanation: во входной двоичной строке 1011 всего три установленных бита.
```

**Пример 2:**

```text
Input: n = 128
Output: 1
Explanation: во входной двоичной строке 10000000 всего один установленный бит.
```

**Пример 3:**

```text
Input: n = 2147483645
Output: 30
Explanation: во входной двоичной строке 1111111111111111111111111111101 всего тридцать установленных битов.
```

## Ограничения

- `1 ≤ n ≤ 2³¹ - 1`

## Дополнительный вопрос

Если эта функция вызывается много раз, как бы вы её оптимизировали?
