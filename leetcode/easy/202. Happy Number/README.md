# 202. Happy Number

**Счастливое число** · 🟢 Easy · Math & Geometry · [LeetCode](https://leetcode.com/problems/happy-number/description/)

## Условие

Напишите алгоритм, который определяет, является ли число `n` счастливым.

**Счастливое число** определяется следующим процессом:

- Начиная с любого положительного целого числа, замените число суммой квадратов его цифр.
- Повторяйте процесс, пока число не станет равным `1` (где оно и останется) или пока оно не **попадёт в бесконечный цикл**, который не включает `1`.
- Те числа, для которых этот процесс **заканчивается на `1`**, являются счастливыми.

Верните `true`, *если* `n` *— счастливое число, и* `false`, *если нет*.

## Примеры

**Пример 1:**

```text
Input: n = 19
Output: true
Explanation:
1² + 9² = 82
8² + 2² = 68
6² + 8² = 100
1² + 0² + 0² = 1
```

**Пример 2:**

```text
Input: n = 2
Output: false
```

## Ограничения

- `1 ≤ n ≤ 2³¹ - 1`
