# 190. Reverse Bits

**Перевернуть биты** · 🟢 Easy · Bit Manipulation · [LeetCode](https://leetcode.com/problems/reverse-bits/description/)

## Условие

Переверните биты заданного 32-битного знакового целого числа.

## Примеры

**Пример 1:**

```text
Input: n = 43261596
Output: 964176192
Explanation:
Число      Двоичная запись
43261596   00000010100101000001111010011100
964176192  00111001011110000010100101000000
```

**Пример 2:**

```text
Input: n = 2147483644
Output: 1073741822
Explanation:
Число       Двоичная запись
2147483644  01111111111111111111111111111100
1073741822  00111111111111111111111111111110
```

## Ограничения

- `0 ≤ n ≤ 2³¹ - 2`
- `n` — чётное число.

## Дополнительный вопрос

Если эта функция вызывается много раз, как бы вы её оптимизировали?
