# 1046. Last Stone Weight

**Вес последнего камня** · 🟢 Easy · Heap / Priority Queue · [LeetCode](https://leetcode.com/problems/last-stone-weight/description/)

## Условие

Дан массив целых чисел `stones`, где `stones[i]` — вес `i`-го камня.

Мы играем в игру с камнями. На каждом ходу мы выбираем **два самых тяжёлых камня** и сталкиваем их друг с другом. Пусть веса двух самых тяжёлых камней — `x` и `y`, причём `x ≤ y`. Результат столкновения:

- Если `x == y`, оба камня уничтожаются.
- Если `x ≠ y`, камень весом `x` уничтожается, а камень весом `y` получает новый вес `y - x`.

В конце игры остаётся **не более одного** камня.

Верните *вес последнего оставшегося камня*. Если камней не осталось, верните `0`.

## Примеры

**Пример 1:**

```text
Input: stones = [2,7,4,1,8,1]
Output: 1
Explanation:
Объединяем 7 и 8, получаем 1, массив превращается в [2,4,1,1,1];
объединяем 2 и 4, получаем 2, массив превращается в [2,1,1,1];
объединяем 2 и 1, получаем 1, массив превращается в [1,1,1];
объединяем 1 и 1, получаем 0, массив превращается в [1] — это и есть вес последнего камня.
```

**Пример 2:**

```text
Input: stones = [1]
Output: 1
```

## Ограничения

- `1 ≤ stones.length ≤ 30`
- `1 ≤ stones[i] ≤ 1000`
