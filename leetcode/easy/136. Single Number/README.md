# 136. Single Number

**Одиночное число** · 🟢 Easy · Bit Manipulation · [LeetCode](https://leetcode.com/problems/single-number/description/)

## Условие

Дан **непустой** массив целых чисел `nums`, в котором каждый элемент встречается *дважды*, кроме одного. Найдите этот единственный элемент.

Нужно реализовать решение с линейной временной сложностью, использующее только константный объём дополнительной памяти.

## Примеры

**Пример 1:**

```text
Input: nums = [2,2,1]
Output: 1
```

**Пример 2:**

```text
Input: nums = [4,1,2,1,2]
Output: 4
```

**Пример 3:**

```text
Input: nums = [1]
Output: 1
```

## Ограничения

- `1 ≤ nums.length ≤ 3 * 10⁴`
- `-3 * 10⁴ ≤ nums[i] ≤ 3 * 10⁴`
- Каждый элемент массива встречается дважды, за исключением одного элемента, который встречается только один раз.
