# 104. Maximum Depth of Binary Tree

**Максимальная глубина бинарного дерева** · 🟢 Easy · Trees · [LeetCode](https://leetcode.com/problems/maximum-depth-of-binary-tree/description/)

## Условие

Дан корень бинарного дерева `root`. Верните *его максимальную глубину*.

**Максимальная глубина** бинарного дерева — это количество узлов на самом длинном пути от корня до самого дальнего листа.

## Примеры

**Пример 1:**

![Пример 1](https://assets.leetcode.com/uploads/2020/11/26/tmp-tree.jpg)

```text
Input: root = [3,9,20,null,null,15,7]
Output: 3
```

**Пример 2:**

```text
Input: root = [1,null,2]
Output: 2
```

## Ограничения

- Количество узлов в дереве — в диапазоне `[0, 10⁴]`.
- `-100 ≤ Node.val ≤ 100`
