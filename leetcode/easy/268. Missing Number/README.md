# 268. Missing Number

**Пропавшее число** · 🟢 Easy · Bit Manipulation · [LeetCode](https://leetcode.com/problems/missing-number/description/)

## Условие

Дан массив `nums`, содержащий `n` различных чисел из диапазона `[0, n]`. Верните *единственное число из этого диапазона, которое отсутствует в массиве*.

## Примеры

**Пример 1:**

```text
Input: nums = [3,0,1]
Output: 2
Explanation: n = 3, так как в массиве 3 числа, поэтому все числа находятся в диапазоне [0,3]. 2 — пропущенное число в этом диапазоне, так как оно не встречается в nums.
```

**Пример 2:**

```text
Input: nums = [0,1]
Output: 2
Explanation: n = 2, так как в массиве 2 числа, поэтому все числа находятся в диапазоне [0,2]. 2 — пропущенное число в этом диапазоне, так как оно не встречается в nums.
```

**Пример 3:**

```text
Input: nums = [9,6,4,2,3,5,7,0,1]
Output: 8
Explanation: n = 9, так как в массиве 9 чисел, поэтому все числа находятся в диапазоне [0,9]. 8 — пропущенное число в этом диапазоне, так как оно не встречается в nums.
```

## Ограничения

- `n == nums.length`
- `1 ≤ n ≤ 10⁴`
- `0 ≤ nums[i] ≤ n`
- Все числа в `nums` **уникальны**.

## Дополнительный вопрос

Сможете ли вы реализовать решение, которое использует только `O(1)` дополнительной памяти и работает за время `O(n)`?
