# 21. Merge Two Sorted Lists

**Объединить два отсортированных списка** · 🟢 Easy · Linked List · [LeetCode](https://leetcode.com/problems/merge-two-sorted-lists/description/)

## Условие

Даны головы двух отсортированных связных списков `list1` и `list2`.

Объедините их в один **отсортированный** список. Список должен быть составлен путём сцепления узлов двух исходных списков.

Верните *голову объединённого списка*.

## Примеры

**Пример 1:**

![Пример 1](https://assets.leetcode.com/uploads/2020/10/03/merge_ex1.jpg)

```text
Input: list1 = [1,2,4], list2 = [1,3,4]
Output: [1,1,2,3,4,4]
```

**Пример 2:**

```text
Input: list1 = [], list2 = []
Output: []
```

**Пример 3:**

```text
Input: list1 = [], list2 = [0]
Output: [0]
```

## Ограничения

- Количество узлов в обоих списках — в диапазоне `[0, 50]`.
- `-100 ≤ Node.val ≤ 100`
- Оба списка `list1` и `list2` отсортированы в порядке **неубывания**.
