# 73. Set Matrix Zeroes

**Установить нули в матрице** · 🟡 Medium · Math & Geometry · [LeetCode](https://leetcode.com/problems/set-matrix-zeroes/description/)

## Условие

Дана целочисленная матрица `matrix` размером `m x n`. Если элемент равен `0`, установите всю его строку и весь его столбец в `0`.

Вы должны сделать это [на месте](https://en.wikipedia.org/wiki/In-place_algorithm).

## Примеры

**Пример 1:**

![Пример 1](https://assets.leetcode.com/uploads/2020/08/17/mat1.jpg)

```text
Input: matrix = [[1,1,1],[1,0,1],[1,1,1]]
Output: [[1,0,1],[0,0,0],[1,0,1]]
```

**Пример 2:**

![Пример 2](https://assets.leetcode.com/uploads/2020/08/17/mat2.jpg)

```text
Input: matrix = [[0,1,2,0],[3,4,5,2],[1,3,1,5]]
Output: [[0,0,0,0],[0,4,5,0],[0,3,1,0]]
```

## Ограничения

- `m == matrix.length`
- `n == matrix[0].length`
- `1 ≤ m, n ≤ 200`
- `-2³¹ ≤ matrix[i][j] ≤ 2³¹ - 1`

## Дополнительный вопрос

- Прямолинейное решение с дополнительной памятью `O(mn)`, вероятно, плохая идея.
- Простое улучшение использует `O(m + n)` памяти, но это всё ещё не лучшее решение.
- Сможете ли вы придумать решение с константной дополнительной памятью?
