# 518. Coin Change II

**Размен монет II** · 🟡 Medium · 2-D Dynamic Programming · [LeetCode](https://leetcode.com/problems/coin-change-ii/description/)

## Условие

Дан целочисленный массив `coins`, представляющий монеты различных номиналов, и целое число `amount`, представляющее общую сумму денег.

Верните *количество комбинаций, которыми можно составить эту сумму*. Если эту сумму невозможно составить ни одной комбинацией монет, верните `0`.

Можно считать, что монет каждого вида бесконечно много.

**Итоговый** ответ **гарантированно** помещается в знаковое **32-битное** целое число.

## Примеры

**Пример 1:**

```text
Input: amount = 5, coins = [1,2,5]
Output: 4
Explanation: есть четыре способа составить сумму:
5=5
5=2+2+1
5=2+1+1+1
5=1+1+1+1+1
```

**Пример 2:**

```text
Input: amount = 3, coins = [2]
Output: 0
Explanation: сумму 3 невозможно составить только из монет номиналом 2.
```

**Пример 3:**

```text
Input: amount = 10, coins = [10]
Output: 1
```

## Ограничения

- `1 ≤ coins.length ≤ 300`
- `1 ≤ coins[i] ≤ 5000`
- Все значения `coins` **уникальны**.
- `0 ≤ amount ≤ 5000`
