# 684. Redundant Connection

**Избыточное соединение** · 🟡 Medium · Graphs · [LeetCode](https://leetcode.com/problems/redundant-connection/description/)

## Условие

В этой задаче дерево — это **неориентированный граф**, который связен и не содержит циклов.

Дан граф, который изначально был деревом из `n` узлов, пронумерованных от `1` до `n`, а затем в него добавили одно ребро. Добавленное ребро соединяет две **разные** вершины из диапазона от `1` до `n`, и такого ребра в графе раньше не было. Граф представлен массивом `edges` длины `n`, где `edges[i] = [aᵢ, bᵢ]` означает, что в графе есть ребро между узлами `aᵢ` и `bᵢ`.

Верните *ребро, которое можно удалить так, чтобы получившийся граф был деревом из* `n` *узлов*. Если ответов несколько, верните тот, который встречается во входных данных последним.

## Примеры

**Пример 1:**

![Пример 1](https://assets.leetcode.com/uploads/2021/05/02/reduntant1-1-graph.jpg)

```text
Input: edges = [[1,2],[1,3],[2,3]]
Output: [2,3]
```

**Пример 2:**

![Пример 2](https://assets.leetcode.com/uploads/2021/05/02/reduntant1-2-graph.jpg)

```text
Input: edges = [[1,2],[2,3],[3,4],[1,4],[1,5]]
Output: [1,4]
```

## Ограничения

- `n == edges.length`
- `3 ≤ n ≤ 1000`
- `edges[i].length == 2`
- `1 ≤ aᵢ < bᵢ ≤ edges.length`
- `aᵢ ≠ bᵢ`
- Повторяющихся рёбер нет.
- Данный граф связный.
