# 167. Two Sum II - Input Array Is Sorted

**Сумма двух II — массив отсортирован** · 🟡 Medium · Two Pointers · [LeetCode](https://leetcode.com/problems/two-sum-ii-input-array-is-sorted/description/)

## Условие

Дан **1-индексированный** массив целых чисел `numbers`, который уже **отсортирован в неубывающем порядке**.

Найдите **два** числа, сумма которых равна заданному числу `target`. Пусть это числа `numbers[index₁]` и `numbers[index₂]`, где `1 ≤ index₁ < index₂ ≤ numbers.length`.

Верните индексы этих двух чисел, `index₁` и `index₂`, в виде массива целых чисел `[index₁, index₂]` длины 2.

Тесты составлены так, что существует **ровно одно решение**. Один и тот же элемент **нельзя** использовать дважды.

Решение должно использовать только константный объём дополнительной памяти.

## Примеры

**Пример 1:**

```text
Input: numbers = [2,7,11,15], target = 9
Output: [1,2]
Explanation: сумма 2 и 7 равна 9. Следовательно, index₁ = 1, index₂ = 2. Возвращаем [1, 2].
```

**Пример 2:**

```text
Input: numbers = [2,3,4], target = 6
Output: [1,3]
Explanation: сумма 2 и 4 равна 6. Следовательно, index₁ = 1, index₂ = 3. Возвращаем [1, 3].
```

**Пример 3:**

```text
Input: numbers = [-1,0], target = -1
Output: [1,2]
Explanation: сумма -1 и 0 равна -1. Следовательно, index₁ = 1, index₂ = 2. Возвращаем [1, 2].
```

## Ограничения

- `2 ≤ numbers.length ≤ 3 * 10⁴`
- `-1000 ≤ numbers[i] ≤ 1000`
- `numbers` **отсортирован в неубывающем порядке**.
- `-1000 ≤ target ≤ 1000`
- Тесты составлены так, что существует **ровно одно решение**.
