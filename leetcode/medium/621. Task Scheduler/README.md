# 621. Task Scheduler

**Планировщик задач** · 🟡 Medium · Heap / Priority Queue · [LeetCode](https://leetcode.com/problems/task-scheduler/description/)

## Условие

Дан массив задач процессора `tasks`, каждая из которых помечена буквой от A до Z, и число `n`. В каждом интервале процессор может либо простаивать, либо выполнить одну задачу. Задачи можно выполнять в любом порядке, но есть ограничение: между двумя задачами с одинаковой меткой должно пройти **не менее** `n` интервалов.

Верните **минимальное** количество интервалов процессора, необходимое для выполнения всех задач.

## Примеры

**Пример 1:**

```text
Input: tasks = ["A","A","A","B","B","B"], n = 2
Output: 8
Explanation: возможная последовательность: A -> B -> простой -> A -> B -> простой -> A -> B.
После выполнения задачи A нужно подождать два интервала, прежде чем снова выполнить A. То же относится к задаче B. В 3-м интервале нельзя выполнить ни A, ни B, поэтому процессор простаивает. К 4-му интервалу A снова можно выполнить, так как прошло 2 интервала.
```

**Пример 2:**

```text
Input: tasks = ["A","C","A","B","D","B"], n = 1
Output: 6
Explanation: возможная последовательность: A -> B -> C -> D -> A -> B.
При интервале охлаждения 1 задачу можно повторить уже после одной другой задачи.
```

**Пример 3:**

```text
Input: tasks = ["A","A","A", "B","B","B"], n = 3
Output: 10
Explanation: возможная последовательность: A -> B -> простой -> простой -> A -> B -> простой -> простой -> A -> B.
Есть только два типа задач, A и B, и их повторения должны разделять 3 интервала. Поэтому между повторениями этих задач приходится дважды простаивать.
```

## Ограничения

- `1 ≤ tasks.length ≤ 10⁴`
- `tasks[i]` — заглавная английская буква.
- `0 ≤ n ≤ 100`
