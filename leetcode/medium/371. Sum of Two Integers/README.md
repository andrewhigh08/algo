# 371. Sum of Two Integers

**Сумма двух целых чисел** · 🟡 Medium · Bit Manipulation · [LeetCode](https://leetcode.com/problems/sum-of-two-integers/description/)

## Условие

Даны два целых числа `a` и `b`. Верните *сумму этих двух чисел, не используя операторы* `+` *и* `-`.

## Примеры

**Пример 1:**

```text
Input: a = 1, b = 2
Output: 3
```

**Пример 2:**

```text
Input: a = 2, b = 3
Output: 5
```

## Ограничения

- `-1000 ≤ a, b ≤ 1000`
