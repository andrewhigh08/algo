# 973. K Closest Points to Origin

**K ближайших точек к началу координат** · 🟡 Medium · Heap / Priority Queue · [LeetCode](https://leetcode.com/problems/k-closest-points-to-origin/description/)

## Условие

Дан массив `points`, где `points[i] = [xᵢ, yᵢ]` — точка на плоскости **X-Y**, и целое число `k`. Верните `k` ближайших к началу координат `(0, 0)` точек.

Расстояние между двумя точками на плоскости **X-Y** — это евклидово расстояние (т. е. `√((x₁ - x₂)² + (y₁ - y₂)²)`).

Ответ можно вернуть в **любом порядке**. **Гарантируется**, что ответ **единственный** (с точностью до порядка точек).

## Примеры

**Пример 1:**

![Пример 1](https://assets.leetcode.com/uploads/2021/03/03/closestplane1.jpg)

```text
Input: points = [[1,3],[-2,2]], k = 1
Output: [[-2,2]]
Explanation:
Расстояние между (1, 3) и началом координат равно sqrt(10).
Расстояние между (-2, 2) и началом координат равно sqrt(8).
Так как sqrt(8) < sqrt(10), точка (-2, 2) ближе к началу координат.
Нужна только k = 1 ближайшая к началу координат точка, поэтому ответ — просто [[-2,2]].
```

**Пример 2:**

```text
Input: points = [[3,3],[5,-1],[-2,4]], k = 2
Output: [[3,3],[-2,4]]
Explanation: ответ [[-2,4],[3,3]] тоже будет принят.
```

## Ограничения

- `1 ≤ k ≤ points.length ≤ 10⁴`
- `-10⁴ ≤ xᵢ, yᵢ ≤ 10⁴`
