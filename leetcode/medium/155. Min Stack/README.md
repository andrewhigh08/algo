# 155. Min Stack

**Минимальный стек** · 🟡 Medium · Stack · [LeetCode](https://leetcode.com/problems/min-stack/description/)

## Условие

Спроектируйте стек, который поддерживает операции push, pop, top и получение минимального элемента за постоянное время.

Реализуйте класс `MinStack`:

- `MinStack()` — инициализирует объект стека.
- `void push(int value)` — помещает элемент `value` в стек.
- `void pop()` — удаляет элемент с вершины стека.
- `int top()` — возвращает верхний элемент стека.
- `int getMin()` — возвращает минимальный элемент стека.

Каждая функция должна работать за `O(1)`.

## Примеры

**Пример 1:**

```text
Input
["MinStack","push","push","push","getMin","pop","top","getMin"]
[[],[-2],[0],[-3],[],[],[],[]]
Output
[null,null,null,null,-3,null,0,-2]

Explanation
MinStack minStack = new MinStack();
minStack.push(-2);
minStack.push(0);
minStack.push(-3);
minStack.getMin(); // возвращает -3
minStack.pop();
minStack.top();    // возвращает 0
minStack.getMin(); // возвращает -2
```

## Ограничения

- `-2³¹ ≤ val ≤ 2³¹ - 1`
- Методы `pop`, `top` и `getMin` всегда вызываются для **непустого** стека.
- Будет сделано не более `3 * 10⁴` вызовов `push`, `pop`, `top` и `getMin`.

## Решение

Код — [main.go](main.go). Два стека: основной `stack` хранит все элементы, а вспомогательный `minStack` — минимумы: при `Push` значение попадает в `minStack`, если оно не больше текущего минимума, а при `Pop` вершина `minStack` снимается, если удаляется элемент, равный минимуму. Поэтому `GetMin` просто возвращает вершину `minStack`. В файле также закомментирован альтернативный вариант с одним стеком, который хранит разности `val - min`.

- Время: `O(1)` на каждую операцию
- Память: `O(n)`
