# 33. Search in Rotated Sorted Array

**Поиск в повёрнутом отсортированном массиве** · 🟡 Medium · Binary Search · [LeetCode](https://leetcode.com/problems/search-in-rotated-sorted-array/description/)

## Условие

Дан целочисленный массив `nums`, отсортированный по возрастанию (с **различными** значениями).

Перед передачей в вашу функцию массив `nums`, **возможно, был повёрнут влево** по неизвестному индексу `k` (`1 ≤ k < nums.length`), так что результирующий массив имеет вид `[nums[k], nums[k+1], ..., nums[n-1], nums[0], nums[1], ..., nums[k-1]]` (индексация **с нуля**). Например, `[0,1,2,4,5,6,7]` может быть повёрнут влево на `3` позиции и стать `[4,5,6,7,0,1,2]`.

Дан массив `nums` **после** возможного поворота и целое число `target`. Верните *индекс `target`, если он есть в `nums`, или `-1`, если его там нет*.

Алгоритм должен работать за время `O(log n)`.

## Примеры

**Пример 1:**

```text
Input: nums = [4,5,6,7,0,1,2], target = 0
Output: 4
```

**Пример 2:**

```text
Input: nums = [4,5,6,7,0,1,2], target = 3
Output: -1
```

**Пример 3:**

```text
Input: nums = [1], target = 0
Output: -1
```

## Ограничения

- `1 ≤ nums.length ≤ 5000`
- `-10⁴ ≤ nums[i] ≤ 10⁴`
- Все значения в `nums` **уникальны**.
- `nums` — возрастающий массив, который, возможно, повёрнут.
- `-10⁴ ≤ target ≤ 10⁴`
