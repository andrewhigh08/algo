# 39. Combination Sum

**Сумма комбинаций** · 🟡 Medium · Backtracking · [LeetCode](https://leetcode.com/problems/combination-sum/description/)

## Условие

Дан массив **различных** целых чисел `candidates` и целевое целое число `target`. Верните *список всех **уникальных комбинаций** чисел из `candidates`, в которых выбранные числа в сумме дают `target`*. Комбинации можно вернуть в **любом порядке**.

**Одно и то же** число может быть выбрано из `candidates` **неограниченное количество раз**. Две комбинации считаются уникальными, если частота хотя бы одного из выбранных чисел в них отличается.

Тесты сгенерированы так, что для каждого входа количество уникальных комбинаций с суммой `target` меньше `150`.

## Примеры

**Пример 1:**

```text
Input: candidates = [2,3,6,7], target = 7
Output: [[2,2,3],[7]]
Explanation:
2 и 3 являются кандидатами, и 2 + 2 + 3 = 7. Обратите внимание, что 2 можно использовать несколько раз.
7 является кандидатом, и 7 = 7.
Это единственные две комбинации.
```

**Пример 2:**

```text
Input: candidates = [2,3,5], target = 8
Output: [[2,2,2,2],[2,3,3],[3,5]]
```

**Пример 3:**

```text
Input: candidates = [2], target = 1
Output: []
```

## Ограничения

- `1 ≤ candidates.length ≤ 30`
- `2 ≤ candidates[i] ≤ 40`
- Все элементы `candidates` **различны**.
- `1 ≤ target ≤ 40`
