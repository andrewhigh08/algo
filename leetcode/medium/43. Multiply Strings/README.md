# 43. Multiply Strings

**Умножение строк** · 🟡 Medium · Math & Geometry · [LeetCode](https://leetcode.com/problems/multiply-strings/description/)

## Условие

Даны два неотрицательных целых числа `num1` и `num2`, представленные в виде строк. Верните произведение `num1` и `num2`, также представленное в виде строки.

**Примечание:** нельзя использовать встроенные библиотеки вроде `BigInteger` или напрямую преобразовывать входные данные в целые числа.

## Примеры

**Пример 1:**

```text
Input: num1 = "2", num2 = "3"
Output: "6"
```

**Пример 2:**

```text
Input: num1 = "123", num2 = "456"
Output: "56088"
```

## Ограничения

- `1 ≤ num1.length, num2.length ≤ 200`
- `num1` и `num2` состоят только из цифр.
- Ни `num1`, ни `num2` не содержат ведущих нулей, за исключением самого числа `0`.
