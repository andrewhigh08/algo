# 133. Clone Graph

**Клонировать граф** · 🟡 Medium · Graphs · [LeetCode](https://leetcode.com/problems/clone-graph/description/)

## Условие

Дана ссылка на узел в **[связном](https://en.wikipedia.org/wiki/Connectivity_(graph_theory)#Connected_graph)** неориентированном графе.

Верните [**глубокую копию**](https://en.wikipedia.org/wiki/Object_copying#Deep_copy) (клон) графа.

Каждый узел графа содержит значение (`int`) и список (`List[Node]`) своих соседей.

```java
class Node {
    public int val;
    public List<Node> neighbors;
}
```

**Формат тестовых случаев:**

Для простоты значение каждого узла совпадает с его индексом (нумерация с единицы). Например, у первого узла `val == 1`, у второго — `val == 2` и так далее. В тестовом случае граф задаётся списком смежности.

**Список смежности** — это набор неупорядоченных **списков**, используемый для представления конечного графа. Каждый список описывает множество соседей одного из узлов графа.

Данный узел всегда будет первым узлом со значением `val = 1`. Нужно вернуть **копию данного узла** как ссылку на клонированный граф.

## Примеры

**Пример 1:**

![Пример 1](https://assets.leetcode.com/uploads/2019/11/04/133_clone_graph_question.png)

```text
Input: adjList = [[2,4],[1,3],[2,4],[1,3]]
Output: [[2,4],[1,3],[2,4],[1,3]]
Explanation: в графе 4 узла.
Соседи 1-го узла (val = 1) — 2-й узел (val = 2) и 4-й узел (val = 4).
Соседи 2-го узла (val = 2) — 1-й узел (val = 1) и 3-й узел (val = 3).
Соседи 3-го узла (val = 3) — 2-й узел (val = 2) и 4-й узел (val = 4).
Соседи 4-го узла (val = 4) — 1-й узел (val = 1) и 3-й узел (val = 3).
```

**Пример 2:**

![Пример 2](https://assets.leetcode.com/uploads/2020/01/07/graph.png)

```text
Input: adjList = [[]]
Output: [[]]
Explanation: обратите внимание, что входные данные содержат один пустой список. Граф состоит только из одного узла со значением val = 1, и у него нет соседей.
```

**Пример 3:**

```text
Input: adjList = []
Output: []
Explanation: это пустой граф, в нём нет ни одного узла.
```

## Ограничения

- Количество узлов в графе — в диапазоне `[0, 100]`.
- `1 ≤ Node.val ≤ 100`
- Значение `Node.val` уникально для каждого узла.
- В графе нет повторяющихся рёбер и петель.
- Граф связный, и все узлы можно посетить, начиная с данного узла.
