# 494. Target Sum

**Целевая сумма** · 🟡 Medium · 2-D Dynamic Programming · [LeetCode](https://leetcode.com/problems/target-sum/description/)

## Условие

Дан целочисленный массив `nums` и целое число `target`.

Вы хотите построить **выражение** из `nums`, поставив перед каждым числом один из символов `'+'` и `'-'`, а затем конкатенировав все числа.

- Например, если `nums = [2, 1]`, можно поставить `'+'` перед `2` и `'-'` перед `1` и конкатенировать их, получив выражение `"+2-1"`.

Верните количество различных **выражений**, которые можно построить и значение которых равно `target`.

## Примеры

**Пример 1:**

```text
Input: nums = [1,1,1,1,1], target = 3
Output: 5
Explanation: есть 5 способов расставить знаки так, чтобы сумма nums была равна target 3.
-1 + 1 + 1 + 1 + 1 = 3
+1 - 1 + 1 + 1 + 1 = 3
+1 + 1 - 1 + 1 + 1 = 3
+1 + 1 + 1 - 1 + 1 = 3
+1 + 1 + 1 + 1 - 1 = 3
```

**Пример 2:**

```text
Input: nums = [1], target = 1
Output: 1
```

## Ограничения

- `1 ≤ nums.length ≤ 20`
- `0 ≤ nums[i] ≤ 1000`
- `0 ≤ sum(nums[i]) ≤ 1000`
- `-1000 ≤ target ≤ 1000`
