# 647. Palindromic Substrings

**Палиндромные подстроки** · 🟡 Medium · 1-D Dynamic Programming · [LeetCode](https://leetcode.com/problems/palindromic-substrings/description/)

## Условие

Дана строка `s`. Верните *количество **палиндромных подстрок** в ней*.

Строка является **палиндромом**, если она читается одинаково как слева направо, так и справа налево.

**Подстрока** — это непрерывная последовательность символов внутри строки.

## Примеры

**Пример 1:**

```text
Input: s = "abc"
Output: 3
Explanation: Три палиндромные строки: "a", "b", "c".
```

**Пример 2:**

```text
Input: s = "aaa"
Output: 6
Explanation: Шесть палиндромных строк: "a", "a", "a", "aa", "aa", "aaa".
```

## Ограничения

- `1 ≤ s.length ≤ 1000`
- `s` состоит из строчных английских букв.
