# 435. Non-overlapping Intervals

**Непересекающиеся интервалы** · 🟡 Medium · Intervals · [LeetCode](https://leetcode.com/problems/non-overlapping-intervals/description/)

## Условие

Дан массив интервалов `intervals`, где `intervals[i] = [startᵢ, endᵢ]`. Верните *минимальное количество интервалов, которые нужно удалить, чтобы остальные интервалы не пересекались*.

**Примечание:** интервалы, которые соприкасаются только в одной точке, считаются **непересекающимися**. Например, `[1, 2]` и `[2, 3]` не пересекаются.

## Примеры

**Пример 1:**

```text
Input: intervals = [[1,2],[2,3],[3,4],[1,3]]
Output: 1
Explanation: можно удалить [1,3], и остальные интервалы не будут пересекаться.
```

**Пример 2:**

```text
Input: intervals = [[1,2],[1,2],[1,2]]
Output: 2
Explanation: нужно удалить два интервала [1,2], чтобы остальные интервалы не пересекались.
```

**Пример 3:**

```text
Input: intervals = [[1,2],[2,3]]
Output: 0
Explanation: удалять ничего не нужно, так как интервалы уже не пересекаются.
```

## Ограничения

- `1 ≤ intervals.length ≤ 10⁵`
- `intervals[i].length == 2`
- `-5 * 10⁴ ≤ startᵢ < endᵢ ≤ 5 * 10⁴`
