# 22. Generate Parentheses

**Сгенерировать скобки** · 🟡 Medium · Stack · [LeetCode](https://leetcode.com/problems/generate-parentheses/description/)

## Условие

Дано `n` пар скобок. Напишите функцию, которая *генерирует все комбинации правильно расставленных скобок*.

## Примеры

**Пример 1:**

```text
Input: n = 3
Output: ["((()))","(()())","(())()","()(())","()()()"]
```

**Пример 2:**

```text
Input: n = 1
Output: ["()"]
```

## Ограничения

- `1 ≤ n ≤ 8`

## Решение

Код — [main.go](main.go). Бэктрекинг: текущая комбинация строится в стеке `stack`. Открывающую скобку можно добавить, пока `openN < n`, а закрывающую — только если `closedN < openN`, поэтому строка всегда остаётся префиксом правильной последовательности; когда `openN == n && closedN == n`, комбинация добавляется в результат. После рекурсивного вызова скобка снимается со стека, и перебор продолжается.

- Время: `O(Cₙ · n)`, то есть `O(4ⁿ / √n)`, где `Cₙ` — n-е число Каталана
- Память: `O(Cₙ · n)`
