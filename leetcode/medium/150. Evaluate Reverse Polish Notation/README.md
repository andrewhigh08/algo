# 150. Evaluate Reverse Polish Notation

**Вычисление обратной польской нотации** · 🟡 Medium · Stack · [LeetCode](https://leetcode.com/problems/evaluate-reverse-polish-notation/description/)

## Условие

Дан массив строк `tokens`, представляющий арифметическое выражение в [обратной польской нотации](https://en.wikipedia.org/wiki/Reverse_Polish_notation).

Вычислите значение выражения. Верните *целое число, равное значению выражения*.

**Примечание:**

- Допустимые операторы: `'+'`, `'-'`, `'*'` и `'/'`.
- Каждый операнд может быть целым числом или другим выражением.
- Деление двух целых чисел всегда **округляет результат к нулю** (дробная часть отбрасывается).
- Деления на ноль не будет.
- Входные данные — корректное арифметическое выражение в обратной польской нотации.
- Ответ и все промежуточные результаты помещаются в **32-битное** целое число.

## Примеры

**Пример 1:**

```text
Input: tokens = ["2","1","+","3","*"]
Output: 9
Explanation: ((2 + 1) * 3) = 9
```

**Пример 2:**

```text
Input: tokens = ["4","13","5","/","+"]
Output: 6
Explanation: (4 + (13 / 5)) = 6
```

**Пример 3:**

```text
Input: tokens = ["10","6","9","3","+","-11","*","/","*","17","+","5","+"]
Output: 22
Explanation: ((10 * (6 / ((9 + 3) * -11))) + 17) + 5
= ((10 * (6 / (12 * -11))) + 17) + 5
= ((10 * (6 / -132)) + 17) + 5
= ((10 * 0) + 17) + 5
= (0 + 17) + 5
= 17 + 5
= 22
```

## Ограничения

- `1 ≤ tokens.length ≤ 10⁴`
- `tokens[i]` — либо оператор `"+"`, `"-"`, `"*"` или `"/"`, либо целое число в диапазоне `[-200, 200]`.

## Решение

Код — [main.go](main.go). Стек операндов: числа кладутся в стек, а на операторе (проверка по множеству `operators`) снимаются два верхних операнда — сначала `operand2`, затем `operand1` — и в стек кладётся результат `operand1 <оператор> operand2`. После обработки всех токенов в стеке остаётся единственное число — ответ.

- Время: `O(n)`
- Память: `O(n)`
