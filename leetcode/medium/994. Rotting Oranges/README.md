# 994. Rotting Oranges

**Гниющие апельсины** · 🟡 Medium · Graphs · [LeetCode](https://leetcode.com/problems/rotting-oranges/description/)

## Условие

Дана сетка `grid` размером `m x n`, где каждая ячейка может иметь одно из трёх значений:

- `0` — пустая ячейка,
- `1` — свежий апельсин,
- `2` — гнилой апельсин.

Каждую минуту любой свежий апельсин, который **соседствует по горизонтали или вертикали** с гнилым апельсином, становится гнилым.

Верните *минимальное количество минут, которое должно пройти, пока ни в одной ячейке не останется свежего апельсина*. Если *это невозможно, верните* `-1`.

## Примеры

**Пример 1:**

![Пример 1](https://assets.leetcode.com/uploads/2019/02/16/oranges.png)

```text
Input: grid = [[2,1,1],[1,1,0],[0,1,1]]
Output: 4
```

**Пример 2:**

```text
Input: grid = [[2,1,1],[0,1,1],[1,0,1]]
Output: -1
Explanation: апельсин в левом нижнем углу (строка 2, столбец 0) никогда не сгниёт, потому что гниение распространяется только по горизонтали и вертикали.
```

**Пример 3:**

```text
Input: grid = [[0,2]]
Output: 0
Explanation: поскольку уже на минуте 0 свежих апельсинов нет, ответ — просто 0.
```

## Ограничения

- `m == grid.length`
- `n == grid[i].length`
- `1 ≤ m, n ≤ 10`
- `grid[i][j]` равно `0`, `1` или `2`.
