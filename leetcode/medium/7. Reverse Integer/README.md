# 7. Reverse Integer

**Перевернуть целое число** · 🟡 Medium · Bit Manipulation · [LeetCode](https://leetcode.com/problems/reverse-integer/description/)

## Условие

Дано знаковое 32-битное целое число `x`. Верните `x` *с перевёрнутыми цифрами*. Если после переворота значение `x` выходит за пределы диапазона знаковых 32-битных целых чисел `[-2³¹, 2³¹ - 1]`, верните `0`.

**Считайте, что среда выполнения не позволяет хранить 64-битные целые числа (ни знаковые, ни беззнаковые).**

## Примеры

**Пример 1:**

```text
Input: x = 123
Output: 321
```

**Пример 2:**

```text
Input: x = -123
Output: -321
```

**Пример 3:**

```text
Input: x = 120
Output: 21
```

## Ограничения

- `-2³¹ ≤ x ≤ 2³¹ - 1`
