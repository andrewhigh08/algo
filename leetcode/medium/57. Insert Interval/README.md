# 57. Insert Interval

**Вставка интервала** · 🟡 Medium · Intervals · [LeetCode](https://leetcode.com/problems/insert-interval/description/)

## Условие

Дан массив непересекающихся интервалов `intervals`, где `intervals[i] = [startᵢ, endᵢ]` — начало и конец `i`-го интервала, причём `intervals` отсортирован по возрастанию `startᵢ`. Также дан интервал `newInterval = [start, end]` — начало и конец ещё одного интервала.

Два интервала считаются пересекающимися, если у них есть **хотя бы одна** общая точка.

Вставьте `newInterval` в `intervals` так, чтобы `intervals` по-прежнему был отсортирован по возрастанию `startᵢ` и по-прежнему не содержал пересекающихся интервалов (при необходимости объедините пересекающиеся интервалы).

Верните `intervals` *после вставки*.

**Примечание:** изменять `intervals` на месте не обязательно. Можно создать новый массив и вернуть его.

## Примеры

**Пример 1:**

```text
Input: intervals = [[1,3],[6,9]], newInterval = [2,5]
Output: [[1,5],[6,9]]
```

**Пример 2:**

```text
Input: intervals = [[1,2],[3,5],[6,7],[8,10],[12,16]], newInterval = [4,8]
Output: [[1,2],[3,10],[12,16]]
Explanation: так как новый интервал [4,8] пересекается с [3,5],[6,7],[8,10].
```

## Ограничения

- `0 ≤ intervals.length ≤ 10⁴`
- `intervals[i].length == 2`
- `0 ≤ startᵢ ≤ endᵢ ≤ 10⁵`
- `intervals` отсортирован по `startᵢ` в порядке **возрастания**.
- `newInterval.length == 2`
- `0 ≤ start ≤ end ≤ 10⁵`
