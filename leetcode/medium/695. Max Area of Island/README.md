# 695. Max Area of Island

**Максимальная площадь острова** · 🟡 Medium · Graphs · [LeetCode](https://leetcode.com/problems/max-area-of-island/description/)

## Условие

Дана бинарная матрица `grid` размером `m x n`. Остров — это группа ячеек со значением `1` (суша), соединённых **по четырём направлениям** (по горизонтали или вертикали). Можно считать, что все четыре края сетки окружены водой.

**Площадь** острова — это количество ячеек со значением `1` в этом острове.

Верните *максимальную **площадь** острова* в `grid`. Если островов нет, верните `0`.

```text

```

## Ограничения

- `m == grid.length`
- `n == grid[i].length`
- `1 ≤ m, n ≤ 50`
- `grid[i][j]` — либо `0`, либо `1`.
