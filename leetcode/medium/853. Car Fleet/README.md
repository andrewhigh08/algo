# 853. Car Fleet

**Автоколонна** · 🟡 Medium · Stack · [LeetCode](https://leetcode.com/problems/car-fleet/description/)

## Условие

Есть `n` автомобилей, которые находятся на заданных расстояниях (в милях) от стартовой отметки `0` и едут к отметке `target`.

Вам даны два целочисленных массива `position` и `speed`, оба длины `n`, где `position[i]` — это стартовая отметка (миля) `i`-го автомобиля, а `speed[i]` — скорость `i`-го автомобиля в милях в час.

Автомобиль не может обогнать другой автомобиль, но может догнать его и затем двигаться рядом с ним со скоростью более медленного автомобиля.

**Автоколонна** — это один автомобиль или группа автомобилей, движущихся рядом друг с другом. Скорость автоколонны равна **минимальной** скорости среди автомобилей этой колонны.

Если автомобиль догоняет автоколонну на отметке `target`, он всё равно считается частью этой автоколонны.

Верните количество автоколонн, которые прибудут в пункт назначения (`target`).

## Примеры

**Пример 1:**

```text
Input: target = 12, position = [10,8,0,5,3], speed = [2,4,1,1,3]
Output: 3
Explanation:
- Автомобили, стартующие с отметок 10 (скорость 2) и 8 (скорость 4), образуют колонну, встречаясь на отметке 12. Колонна формируется в пункте назначения target.
- Автомобиль, стартующий с отметки 0 (скорость 1), никого не догоняет, поэтому образует колонну сам по себе.
- Автомобили, стартующие с отметок 5 (скорость 1) и 3 (скорость 3), образуют колонну, встречаясь на отметке 6. Колонна движется со скоростью 1, пока не достигнет target.
```

**Пример 2:**

```text
Input: target = 10, position = [3], speed = [3]
Output: 1
Explanation: автомобиль всего один, следовательно, и автоколонна одна.
```

**Пример 3:**

```text
Input: target = 100, position = [0,2,4], speed = [4,2,1]
Output: 1
Explanation:
- Автомобили, стартующие с отметок 0 (скорость 4) и 2 (скорость 2), образуют колонну, встречаясь на отметке 4. Автомобиль, стартующий с отметки 4 (скорость 1), к этому моменту доезжает до отметки 5.
- Затем колонна на отметке 4 (скорость 2) и автомобиль на отметке 5 (скорость 1) становятся одной колонной, встречаясь на отметке 6. Колонна движется со скоростью 1, пока не достигнет target.
```

## Ограничения

- `n == position.length == speed.length`
- `1 ≤ n ≤ 10⁵`
- `0 < target ≤ 10⁶`
- `0 ≤ position[i] < target`
- Все значения в `position` **уникальны**.
- `0 < speed[i] ≤ 10⁶`
