# 11. Container With Most Water

**Контейнер с наибольшим количеством воды** · 🟡 Medium · Two Pointers · [LeetCode](https://leetcode.com/problems/container-with-most-water/description/)

## Условие

Дан массив целых чисел `height` длины `n`. Нарисованы `n` вертикальных линий так, что концы `i`-й линии находятся в точках `(i, 0)` и `(i, height[i])`.

Найдите две линии, которые вместе с осью X образуют контейнер, вмещающий наибольшее количество воды.

Верните *максимальное количество воды, которое может вместить контейнер*.

**Обратите внимание**, что контейнер нельзя наклонять.

## Примеры

**Пример 1:**

![Пример 1](https://s3-lc-upload.s3.amazonaws.com/uploads/2018/07/17/question_11.jpg)

```text
Input: height = [1,8,6,2,5,4,8,3,7]
Output: 49
Explanation: вертикальные линии на рисунке выше задаются массивом [1,8,6,2,5,4,8,3,7]. В этом случае наибольшая площадь воды (синяя область), которую может вместить контейнер, равна 49.
```

**Пример 2:**

```text
Input: height = [1,1]
Output: 1
```

## Ограничения

- `n == height.length`
- `2 ≤ n ≤ 10⁵`
- `0 ≤ height[i] ≤ 10⁴`
