# 138. Copy List with Random Pointer

**Копирование списка со случайным указателем** · 🟡 Medium · Linked List · [LeetCode](https://leetcode.com/problems/copy-list-with-random-pointer/description/)

## Условие

Дан связный список длины `n`, в котором каждый узел содержит дополнительный случайный указатель: он может указывать на любой узел списка или на `null`.

Создайте [**глубокую копию**](https://en.wikipedia.org/wiki/Object_copying#Deep_copy) списка. Глубокая копия должна состоять ровно из `n` **совершенно новых** узлов, значение каждого из которых равно значению соответствующего исходного узла. Указатели `next` и `random` новых узлов должны указывать на новые узлы скопированного списка так, чтобы указатели в исходном и скопированном списках представляли одно и то же состояние списка. **Ни один указатель в новом списке не должен указывать на узлы исходного списка.**

Например, если в исходном списке есть два узла `X` и `Y`, где `X.random --> Y`, то для соответствующих им узлов `x` и `y` в скопированном списке `x.random --> y`.

Верните *голову скопированного связного списка*.

Во входных и выходных данных связный список представлен как список из `n` узлов. Каждый узел записывается парой `[val, random_index]`, где:

- `val` — целое число, равное `Node.val`;
- `random_index` — индекс узла (от `0` до `n-1`), на который указывает указатель `random`, или `null`, если он не указывает ни на какой узел.

Вашему коду будет передана **только** голова `head` исходного связного списка.

## Примеры

```

```

## Ограничения

- `0 ≤ n ≤ 1000`
- `-10⁴ ≤ Node.val ≤ 10⁴`
- `Node.random` равен `null` или указывает на какой-либо узел связного списка.
