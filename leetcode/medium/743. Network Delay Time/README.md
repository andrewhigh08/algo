# 743. Network Delay Time

**Время задержки сети** · 🟡 Medium · Advanced Graphs · [LeetCode](https://leetcode.com/problems/network-delay-time/description/)

## Условие

Дана сеть из `n` узлов, пронумерованных от `1` до `n`. Также дан `times` — список времён передачи сигнала в виде ориентированных рёбер `times[i] = (uᵢ, vᵢ, wᵢ)`, где `uᵢ` — исходный узел, `vᵢ` — целевой узел, а `wᵢ` — время, за которое сигнал проходит от источника до цели.

Мы отправляем сигнал из заданного узла `k`. Верните ***минимальное*** *время, за которое сигнал получат все* `n` *узлов*. Если сигнал не может дойти до всех `n` узлов, верните `-1`.

## Примеры

**Пример 1:**

![Пример 1](https://assets.leetcode.com/uploads/2019/05/23/931_example_1.png)

```text
Input: times = [[2,1,1],[2,3,1],[3,4,1]], n = 4, k = 2
Output: 2
```

**Пример 2:**

```text
Input: times = [[1,2,1]], n = 2, k = 1
Output: 1
```

**Пример 3:**

```text
Input: times = [[1,2,1]], n = 2, k = 2
Output: -1
```

## Ограничения

- `1 ≤ k ≤ n ≤ 100`
- `1 ≤ times.length ≤ 6000`
- `times[i].length == 3`
- `1 ≤ uᵢ, vᵢ ≤ n`
- `uᵢ ≠ vᵢ`
- `0 ≤ wᵢ ≤ 100`
- Все пары `(uᵢ, vᵢ)` **уникальны** (т. е. кратных рёбер нет).
