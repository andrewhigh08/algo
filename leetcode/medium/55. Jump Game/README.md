# 55. Jump Game

**Игра в прыжки** · 🟡 Medium · Greedy · [LeetCode](https://leetcode.com/problems/jump-game/description/)

## Условие

Дан целочисленный массив `nums`. Изначально вы находитесь на **первом индексе** массива, и каждый элемент массива — это максимальная длина прыжка из этой позиции.

Верните `true`, *если вы можете достичь последнего индекса*, или `false` *в противном случае*.

## Примеры

**Пример 1:**

```text
Input: nums = [2,3,1,1,4]
Output: true
Explanation: прыгните на 1 шаг от индекса 0 к индексу 1, затем на 3 шага — к последнему индексу.
```

**Пример 2:**

```text
Input: nums = [3,2,1,0,4]
Output: false
Explanation: что бы вы ни делали, вы всегда окажетесь на индексе 3. Его максимальная длина прыжка равна 0, поэтому достичь последнего индекса невозможно.
```

## Ограничения

- `1 ≤ nums.length ≤ 10⁴`
- `0 ≤ nums[i] ≤ 10⁵`
