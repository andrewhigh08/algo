# 53. Maximum Subarray

**Максимальный подмассив** · 🟡 Medium · Greedy · [LeetCode](https://leetcode.com/problems/maximum-subarray/description/)

## Условие

Дан целочисленный массив `nums`. Найдите подмассив с наибольшей суммой и верните *его сумму*.

## Примеры

**Пример 1:**

```text
Input: nums = [-2,1,-3,4,-1,2,1,-5,4]
Output: 6
Explanation: подмассив [4,-1,2,1] имеет наибольшую сумму 6.
```

**Пример 2:**

```text
Input: nums = [1]
Output: 1
Explanation: подмассив [1] имеет наибольшую сумму 1.
```

**Пример 3:**

```text
Input: nums = [5,4,-1,7,8]
Output: 23
Explanation: подмассив [5,4,-1,7,8] имеет наибольшую сумму 23.
```

## Ограничения

- `1 ≤ nums.length ≤ 10⁵`
- `-10⁴ ≤ nums[i] ≤ 10⁴`

## Дополнительный вопрос

Если вы уже нашли решение за `O(n)`, попробуйте написать другое решение методом **«разделяй и властвуй»** — он более тонкий.
