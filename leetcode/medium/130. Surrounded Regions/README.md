# 130. Surrounded Regions

**Окружённые регионы** · 🟡 Medium · Graphs · [LeetCode](https://leetcode.com/problems/surrounded-regions/description/)

## Условие

Дана матрица `board` размером `m x n`, содержащая **буквы** `'X'` и `'O'`. **Захватите регионы**, которые **окружены**:

- **Связность**: ячейка связана с соседними ячейками по горизонтали и по вертикали.
- **Регион**: чтобы образовать регион, **соедините все** связанные друг с другом ячейки `'O'`.
- **Окружение**: регион окружён, если ни одна из его ячеек `'O'` не находится на краю доски. Такие регионы **полностью окружены** ячейками `'X'`.

Чтобы захватить **окружённый регион**, замените в нём все `'O'` на `'X'` **на месте**, прямо в исходной доске. Возвращать ничего не нужно.

## Примеры

**Пример 1:**

![Пример 1](https://assets.leetcode.com/uploads/2021/02/19/xogrid.jpg)

```text
Input: board = [["X","X","X","X"],["X","O","O","X"],["X","X","O","X"],["X","O","X","X"]]
Output: [["X","X","X","X"],["X","X","X","X"],["X","X","X","X"],["X","O","X","X"]]
Explanation: на рисунке выше нижний регион не захвачен, потому что он находится на краю доски и не может быть окружён.
```

**Пример 2:**

```text
Input: board = [["X"]]
Output: [["X"]]
```

## Ограничения

- `m == board.length`
- `n == board[i].length`
- `1 ≤ m, n ≤ 200`
- `board[i][j]` — `'X'` или `'O'`.
