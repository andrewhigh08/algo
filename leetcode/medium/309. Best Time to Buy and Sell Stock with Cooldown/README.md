# 309. Best Time to Buy and Sell Stock with Cooldown

**Лучшее время для покупки и продажи акций с охлаждением** · 🟡 Medium · 2-D Dynamic Programming · [LeetCode](https://leetcode.com/problems/best-time-to-buy-and-sell-stock-with-cooldown/description/)

## Условие

Дан массив `prices`, где `prices[i]` — цена акции в `i`-й день.

Найдите максимальную прибыль, которую можно получить. Можно совершить сколько угодно транзакций (т. е. несколько раз купить и продать по одной акции) со следующими ограничениями:

- После продажи акции нельзя купить акцию на следующий день (т. е. охлаждение длится один день).

**Примечание:** нельзя участвовать в нескольких транзакциях одновременно (т. е. прежде чем снова купить акцию, нужно продать предыдущую).

## Примеры

**Пример 1:**

```text
Input: prices = [1,2,3,0,2]
Output: 3
Explanation: транзакции = [купить, продать, охлаждение, купить, продать]
```

**Пример 2:**

```text
Input: prices = [1]
Output: 0
```

## Ограничения

- `1 ≤ prices.length ≤ 5000`
- `0 ≤ prices[i] ≤ 1000`
