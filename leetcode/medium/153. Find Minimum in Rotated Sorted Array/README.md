# 153. Find Minimum in Rotated Sorted Array

**Найти минимум в повёрнутом отсортированном массиве** · 🟡 Medium · Binary Search · [LeetCode](https://leetcode.com/problems/find-minimum-in-rotated-sorted-array/description/)

## Условие

Предположим, массив длины `n`, отсортированный по возрастанию, **повернули** от `1` до `n` раз. Например, массив `nums = [0,1,2,4,5,6,7]` может стать таким:

- `[4,5,6,7,0,1,2]`, если его повернули `4` раза;
- `[0,1,2,4,5,6,7]`, если его повернули `7` раз.

Обратите внимание: **поворот** массива `[a[0], a[1], a[2], ..., a[n-1]]` один раз даёт массив `[a[n-1], a[0], a[1], a[2], ..., a[n-2]]`.

Дан отсортированный повёрнутый массив `nums` из **уникальных** элементов. Верните *минимальный элемент этого массива*.

Алгоритм должен работать за время `O(log n)`.

## Примеры

**Пример 1:**

```text
Input: nums = [3,4,5,1,2]
Output: 1
Explanation: исходный массив [1,2,3,4,5] повернули 3 раза.
```

**Пример 2:**

```text
Input: nums = [4,5,6,7,0,1,2]
Output: 0
Explanation: исходный массив [0,1,2,4,5,6,7] повернули 4 раза.
```

**Пример 3:**

```text
Input: nums = [11,13,15,17]
Output: 11
Explanation: исходный массив [11,13,15,17] повернули 4 раза.
```

## Ограничения

- `n == nums.length`
- `1 ≤ n ≤ 5000`
- `-5000 ≤ nums[i] ≤ 5000`
- Все числа в `nums` **уникальны**.
- `nums` отсортирован и повёрнут от `1` до `n` раз.
