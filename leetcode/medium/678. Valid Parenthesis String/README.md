# 678. Valid Parenthesis String

**Валидная строка со скобками** · 🟡 Medium · Greedy · [LeetCode](https://leetcode.com/problems/valid-parenthesis-string/description/)

## Условие

Дана строка `s`, содержащая только символы трёх типов: `'('`, `')'` и `'*'`. Верните `true`, *если* `s` **валидна**.

Следующие правила определяют **валидную** строку:

- Любая левая скобка `'('` должна иметь соответствующую правую скобку `')'`.
- Любая правая скобка `')'` должна иметь соответствующую левую скобку `'('`.
- Левая скобка `'('` должна идти перед соответствующей правой скобкой `')'`.
- `'*'` можно рассматривать как одну правую скобку `')'`, одну левую скобку `'('` или пустую строку `""`.

## Примеры

**Пример 1:**

```text
Input: s = "()"
Output: true
```

**Пример 2:**

```text
Input: s = "(*)"
Output: true
```

**Пример 3:**

```text
Input: s = "(*))"
Output: true
```

**Пример 4:**

```text
Input: s = "("
Output: false
```

## Ограничения

- `1 ≤ s.length ≤ 100`
- `s[i]` — это `'('`, `')'` или `'*'`.
