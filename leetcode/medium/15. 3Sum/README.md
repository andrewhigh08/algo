# 15. 3Sum

**Сумма трёх чисел** · 🟡 Medium · Two Pointers · [LeetCode](https://leetcode.com/problems/3sum/description/)

## Условие

Дан массив целых чисел `nums`. Верните все триплеты `[nums[i], nums[j], nums[k]]`, такие что `i ≠ j`, `i ≠ k` и `j ≠ k`, а также `nums[i] + nums[j] + nums[k] == 0`.

Обратите внимание, что в ответе не должно быть повторяющихся триплетов.

## Примеры

**Пример 1:**

```text
Input: nums = [-1,0,1,2,-1,-4]
Output: [[-1,-1,2],[-1,0,1]]
Explanation:
nums[0] + nums[1] + nums[2] = (-1) + 0 + 1 = 0.
nums[1] + nums[2] + nums[4] = 0 + 1 + (-1) = 0.
nums[0] + nums[3] + nums[4] = (-1) + 2 + (-1) = 0.
Различные триплеты — [-1,0,1] и [-1,-1,2].
Обратите внимание, что ни порядок триплетов в ответе, ни порядок чисел в триплете не важен.
```

**Пример 2:**

```text
Input: nums = [0,1,1]
Output: []
Explanation: единственный возможный триплет в сумме не даёт 0.
```

**Пример 3:**

```text
Input: nums = [0,0,0]
Output: [[0,0,0]]
Explanation: единственный возможный триплет в сумме даёт 0.
```

## Ограничения

- `3 ≤ nums.length ≤ 3000`
- `-10⁵ ≤ nums[i] ≤ 10⁵`
