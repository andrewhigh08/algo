# 1448. Count Good Nodes in Binary Tree

**Подсчет хороших узлов в бинарном дереве** · 🟡 Medium · Trees · [LeetCode](https://leetcode.com/problems/count-good-nodes-in-binary-tree/description/)

## Условие

Дано бинарное дерево `root`. Узел `X` в дереве называется **хорошим**, если на пути от корня к `X` нет узлов со значением *больше*, чем у `X`.

Верните количество **хороших** узлов в бинарном дереве.

## Примеры

**Пример 1:**

![Пример 1](https://assets.leetcode.com/uploads/2020/04/02/test_sample_1.png)

```text
Input: root = [3,1,4,3,null,1,5]
Output: 4
Explanation: хорошие узлы выделены синим.
Корневой узел (3) всегда хороший.
Узел 4 -> (3,4): 4 — максимальное значение на пути от корня.
Узел 5 -> (3,4,5): 5 — максимальное значение на пути.
Узел 3 -> (3,1,3): 3 — максимальное значение на пути.
```

**Пример 2:**

![Пример 2](https://assets.leetcode.com/uploads/2020/04/02/test_sample_2.png)

```text
Input: root = [3,3,null,4,2]
Output: 3
Explanation: узел 2 -> (3, 3, 2) не является хорошим, потому что "3" больше него.
```

**Пример 3:**

```text
Input: root = [1]
Output: 1
Explanation: корень считается хорошим.
```

## Ограничения

- Количество узлов в бинарном дереве — в диапазоне `[1, 10⁵]`.
- Значение каждого узла — в диапазоне `[-10⁴, 10⁴]`.
