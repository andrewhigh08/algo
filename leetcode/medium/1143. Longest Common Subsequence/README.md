# 1143. Longest Common Subsequence

**Самая длинная общая подпоследовательность** · 🟡 Medium · 2-D Dynamic Programming · [LeetCode](https://leetcode.com/problems/longest-common-subsequence/description/)

## Условие

Даны две строки `text1` и `text2`. Верните *длину их самой длинной **общей подпоследовательности***. Если **общей подпоследовательности** нет, верните `0`.

**Подпоследовательность** строки — это новая строка, полученная из исходной удалением некоторых символов (возможно, ни одного) без изменения относительного порядка оставшихся символов.

- Например, `"ace"` — подпоследовательность строки `"abcde"`.

**Общая подпоследовательность** двух строк — это подпоследовательность, общая для обеих строк.

## Примеры

**Пример 1:**

```text
Input: text1 = "abcde", text2 = "ace"
Output: 3
Explanation: самая длинная общая подпоследовательность — "ace", её длина равна 3.
```

**Пример 2:**

```text
Input: text1 = "abc", text2 = "abc"
Output: 3
Explanation: самая длинная общая подпоследовательность — "abc", её длина равна 3.
```

**Пример 3:**

```text
Input: text1 = "abc", text2 = "def"
Output: 0
Explanation: общей подпоследовательности нет, поэтому результат равен 0.
```

## Ограничения

- `1 ≤ text1.length, text2.length ≤ 1000`
- `text1` и `text2` состоят только из строчных английских букв.
