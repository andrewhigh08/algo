# 210. Course Schedule II

**Расписание курсов II** · 🟡 Medium · Graphs · [LeetCode](https://leetcode.com/problems/course-schedule-ii/description/)

## Условие

Всего вам нужно пройти `numCourses` курсов, пронумерованных от `0` до `numCourses - 1`. Дан массив `prerequisites`, где `prerequisites[i] = [aᵢ, bᵢ]` означает, что вы **обязательно** должны сначала пройти курс `bᵢ`, если хотите пройти курс `aᵢ`.

- Например, пара `[0, 1]` означает, что для прохождения курса `0` нужно сначала пройти курс `1`.

Верните *порядок, в котором нужно проходить курсы, чтобы закончить их все*. Если правильных ответов несколько, верните **любой** из них. Если закончить все курсы невозможно, верните **пустой массив**.

## Примеры

**Пример 1:**

```text
Input: numCourses = 2, prerequisites = [[1,0]]
Output: [0,1]
Explanation: всего нужно пройти 2 курса. Чтобы пройти курс 1, нужно сначала закончить курс 0. Поэтому правильный порядок курсов — [0,1].
```

**Пример 2:**

```text
Input: numCourses = 4, prerequisites = [[1,0],[2,0],[3,1],[3,2]]
Output: [0,2,1,3]
Explanation: всего нужно пройти 4 курса. Чтобы пройти курс 3, нужно закончить оба курса 1 и 2. Оба курса 1 и 2 нужно проходить после того, как закончен курс 0.
Поэтому один правильный порядок курсов — [0,1,2,3]. Другой правильный порядок — [0,2,1,3].
```

**Пример 3:**

```text
Input: numCourses = 1, prerequisites = []
Output: [0]
```

## Ограничения

- `1 ≤ numCourses ≤ 2000`
- `0 ≤ prerequisites.length ≤ numCourses * (numCourses - 1)`
- `prerequisites[i].length == 2`
- `0 ≤ aᵢ, bᵢ < numCourses`
- `aᵢ ≠ bᵢ`
- Все пары `[aᵢ, bᵢ]` **различны**.
