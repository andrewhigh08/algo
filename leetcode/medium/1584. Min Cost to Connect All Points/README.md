# 1584. Min Cost to Connect All Points

**Минимальная стоимость соединения всех точек** · 🟡 Medium · Advanced Graphs · [LeetCode](https://leetcode.com/problems/min-cost-to-connect-all-points/description/)

## Условие

Дан массив `points` с целочисленными координатами точек на плоскости, где `points[i] = [xᵢ, yᵢ]`.

Стоимость соединения двух точек `[xᵢ, yᵢ]` и `[xⱼ, yⱼ]` — это **манхэттенское расстояние** между ними: `|xᵢ - xⱼ| + |yᵢ - yⱼ|`, где `|val|` — модуль числа `val`.

Верните *минимальную стоимость, за которую можно соединить все точки*. Все точки соединены, если между любыми двумя точками существует **ровно один** простой путь.

## Ограничения

- `1 ≤ points.length ≤ 1000`
- `-10⁶ ≤ xᵢ, yᵢ ≤ 10⁶`
- Все пары `(xᵢ, yᵢ)` различны.
