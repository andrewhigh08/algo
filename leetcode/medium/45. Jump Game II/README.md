# 45. Jump Game II

**Игра в прыжки II** · 🟡 Medium · Greedy · [LeetCode](https://leetcode.com/problems/jump-game-ii/description/)

## Условие

Дан **0-индексированный** массив целых чисел `nums` длины `n`. Изначально вы находитесь на индексе `0`.

Каждый элемент `nums[i]` — это максимальная длина прыжка вперёд с индекса `i`. Другими словами, находясь на индексе `i`, вы можете прыгнуть на любой индекс `(i + j)`, где:

- `0 ≤ j ≤ nums[i]` и
- `i + j < n`

Верните *минимальное количество прыжков, чтобы достичь индекса* `n - 1`. Тесты составлены так, что до индекса `n - 1` всегда можно добраться.

## Примеры

**Пример 1:**

```text
Input: nums = [2,3,1,1,4]
Output: 2
Explanation: минимальное количество прыжков до последнего индекса равно 2. Прыгните на 1 шаг от индекса 0 к индексу 1, затем на 3 шага — к последнему индексу.
```

**Пример 2:**

```text
Input: nums = [2,3,0,1,4]
Output: 2
```

## Ограничения

- `1 ≤ nums.length ≤ 10⁴`
- `0 ≤ nums[i] ≤ 1000`
- Гарантируется, что до `nums[n - 1]` можно добраться.
