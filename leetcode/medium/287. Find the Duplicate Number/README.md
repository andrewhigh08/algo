# 287. Find the Duplicate Number

**Найти дублирующееся число** · 🟡 Medium · Linked List · [LeetCode](https://leetcode.com/problems/find-the-duplicate-number/description/)

## Условие

Дан массив целых чисел `nums`, содержащий `n + 1` целых чисел, каждое из которых находится в диапазоне `[1, n]` включительно.

В `nums` есть только **одно повторяющееся число**. Верните *это повторяющееся число*.

Задачу нужно решить **без** изменения массива `nums`, используя только константную дополнительную память.

## Примеры

**Пример 1:**

```text
Input: nums = [1,3,4,2,2]
Output: 2
```

**Пример 2:**

```text
Input: nums = [3,1,3,4,2]
Output: 3
```

**Пример 3:**

```text
Input: nums = [3,3,3,3,3]
Output: 3
```

## Ограничения

- `1 ≤ n ≤ 10⁵`
- `nums.length == n + 1`
- `1 ≤ nums[i] ≤ n`
- Все целые числа в `nums` встречаются только **один раз**, за исключением **ровно одного числа**, которое встречается **два или более раз**.

## Дополнительный вопрос

- Как доказать, что в `nums` обязательно есть хотя бы одно повторяющееся число?
- Сможете ли вы решить задачу за линейное время?
