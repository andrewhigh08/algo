# 239. Sliding Window Maximum

**Максимум скользящего окна** · 🔴 Hard · Sliding Window · [LeetCode](https://leetcode.com/problems/sliding-window-maximum/description/)

## Условие

Дан массив целых чисел `nums`. Скользящее окно размера `k` перемещается от самого левого края массива к самому правому. В окне видны только `k` чисел. Каждый раз окно сдвигается вправо на одну позицию.

Верните *массив максимальных значений для каждого положения скользящего окна*.

## Примеры

**Пример 1:**

```text
Input: nums = [1,3,-1,-3,5,3,6,7], k = 3
Output: [3,3,5,5,6,7]
Explanation:
Положение окна                Макс.
--------------                -----
[1  3  -1] -3  5  3  6  7       3
 1 [3  -1  -3] 5  3  6  7       3
 1  3 [-1  -3  5] 3  6  7       5
 1  3  -1 [-3  5  3] 6  7       5
 1  3  -1  -3 [5  3  6] 7       6
 1  3  -1  -3  5 [3  6  7]      7
```

**Пример 2:**

```text
Input: nums = [1], k = 1
Output: [1]
```

## Ограничения

- `1 ≤ nums.length ≤ 10⁵`
- `-10⁴ ≤ nums[i] ≤ 10⁴`
- `1 ≤ k ≤ nums.length`
