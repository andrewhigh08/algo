# 10. Regular Expression Matching

**Сопоставление регулярных выражений** · 🔴 Hard · 2-D Dynamic Programming · [LeetCode](https://leetcode.com/problems/regular-expression-matching/description/)

## Условие

Даны входная строка `s` и шаблон `p`. Реализуйте сопоставление с регулярным выражением с поддержкой `'.'` и `'*'`, где:

- `'.'` соответствует любому одиночному символу;
- `'*'` соответствует нулю или более повторениям предшествующего элемента.

Верните логическое значение: покрывает ли сопоставление всю входную строку (а не её часть).

## Примеры

**Пример 1:**

```text
Input: s = "aa", p = "a"
Output: false
Explanation: "a" не соответствует всей строке "aa".
```

**Пример 2:**

```text
Input: s = "aa", p = "a*"
Output: true
Explanation: '*' означает ноль или более повторений предшествующего элемента, то есть 'a'. Значит, повторив 'a' один раз, получаем "aa".
```

**Пример 3:**

```text
Input: s = "ab", p = ".*"
Output: true
Explanation: ".*" означает "ноль или более (*) любых символов (.)".
```

## Ограничения

- `1 ≤ s.length ≤ 20`
- `1 ≤ p.length ≤ 20`
- `s` содержит только строчные английские буквы.
- `p` содержит только строчные английские буквы, `'.'` и `'*'`.
- Гарантируется, что для каждого вхождения символа `'*'` перед ним есть допустимый символ для сопоставления.
