# 23. Merge k Sorted Lists

**Объединить k отсортированных списков** · 🔴 Hard · Linked List · [LeetCode](https://leetcode.com/problems/merge-k-sorted-lists/description/)

## Условие

Дан массив `lists` из `k` связных списков, каждый из которых отсортирован по возрастанию.

*Объедините все связные списки в один отсортированный связный список и верните его.*

## Примеры

**Пример 1:**

```text
Input: lists = [[1,4,5],[1,3,4],[2,6]]
Output: [1,1,2,3,4,4,5,6]
Explanation: связные списки:
[
  1->4->5,
  1->3->4,
  2->6
]
после объединения в один отсортированный список:
1->1->2->3->4->4->5->6
```

**Пример 2:**

```text
Input: lists = []
Output: []
```

**Пример 3:**

```text
Input: lists = [[]]
Output: []
```

## Ограничения

- `k == lists.length`
- `0 ≤ k ≤ 10⁴`
- `0 ≤ lists[i].length ≤ 500`
- `-10⁴ ≤ lists[i][j] ≤ 10⁴`
- `lists[i]` отсортирован по **возрастанию**.
- Сумма `lists[i].length` не превышает `10⁴`.
