# 1851. Minimum Interval to Include Each Query

**Минимальный интервал для включения каждого запроса** · 🔴 Hard · Intervals · [LeetCode](https://leetcode.com/problems/minimum-interval-to-include-each-query/description/)

## Условие

Дан двумерный массив целых чисел `intervals`, где `intervals[i] = [leftᵢ, rightᵢ]` описывает `i`-й интервал, который начинается в `leftᵢ` и заканчивается в `rightᵢ` **(включительно)**. **Размер** интервала — это количество целых чисел, которые он содержит, или, более формально, `rightᵢ - leftᵢ + 1`.

Также дан массив целых чисел `queries`. Ответ на `j`-й запрос — это **размер наименьшего интервала** `i`, такого что `leftᵢ ≤ queries[j] ≤ rightᵢ`. Если такого интервала нет, ответ равен `-1`.

Верните *массив ответов на запросы*.

## Примеры

**Пример 1:**

```text
Input: intervals = [[1,4],[2,4],[3,6],[4,4]], queries = [2,3,4,5]
Output: [3,3,1,4]
Explanation: запросы обрабатываются следующим образом:
- Запрос = 2: интервал [2,4] — наименьший интервал, содержащий 2. Ответ: 4 - 2 + 1 = 3.
- Запрос = 3: интервал [2,4] — наименьший интервал, содержащий 3. Ответ: 4 - 2 + 1 = 3.
- Запрос = 4: интервал [4,4] — наименьший интервал, содержащий 4. Ответ: 4 - 4 + 1 = 1.
- Запрос = 5: интервал [3,6] — наименьший интервал, содержащий 5. Ответ: 6 - 3 + 1 = 4.
```

**Пример 2:**

```text
Input: intervals = [[2,3],[2,5],[1,8],[20,25]], queries = [2,19,5,22]
Output: [2,-1,4,6]
Explanation: запросы обрабатываются следующим образом:
- Запрос = 2: интервал [2,3] — наименьший интервал, содержащий 2. Ответ: 3 - 2 + 1 = 2.
- Запрос = 19: ни один из интервалов не содержит 19. Ответ: -1.
- Запрос = 5: интервал [2,5] — наименьший интервал, содержащий 5. Ответ: 5 - 2 + 1 = 4.
- Запрос = 22: интервал [20,25] — наименьший интервал, содержащий 22. Ответ: 25 - 20 + 1 = 6.
```

## Ограничения

- `1 ≤ intervals.length ≤ 10⁵`
- `1 ≤ queries.length ≤ 10⁵`
- `intervals[i].length == 2`
- `1 ≤ leftᵢ ≤ rightᵢ ≤ 10⁷`
- `1 ≤ queries[j] ≤ 10⁷`
