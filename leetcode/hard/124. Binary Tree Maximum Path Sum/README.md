# 124. Binary Tree Maximum Path Sum

**Максимальная сумма пути в бинарном дереве** · 🔴 Hard · Trees · [LeetCode](https://leetcode.com/problems/binary-tree-maximum-path-sum/description/)

## Условие

**Путь** в бинарном дереве — это последовательность узлов, в которой каждая пара соседних узлов соединена ребром. Узел может встречаться в последовательности **не более одного раза**. Обратите внимание, что путь не обязательно должен проходить через корень.

**Сумма пути** — это сумма значений узлов на этом пути.

Дан корень бинарного дерева `root`. Верните *максимальную **сумму пути** среди всех **непустых** путей*.

## Примеры

**Пример 1:**

![Пример 1](https://assets.leetcode.com/uploads/2020/10/13/exx1.jpg)

```text
Input: root = [1,2,3]
Output: 6
Explanation: оптимальный путь 2 -> 1 -> 3 с суммой пути 2 + 1 + 3 = 6.
```

**Пример 2:**

![Пример 2](https://assets.leetcode.com/uploads/2020/10/13/exx2.jpg)

```text
Input: root = [-10,9,20,null,null,15,7]
Output: 42
Explanation: оптимальный путь 15 -> 20 -> 7 с суммой пути 15 + 20 + 7 = 42.
```

## Ограничения

- Количество узлов в дереве — в диапазоне `[1, 3 * 10⁴]`.
- `-1000 ≤ Node.val ≤ 1000`
