# 51. N-Queens

**N ферзей** · 🔴 Hard · Backtracking · [LeetCode](https://leetcode.com/problems/n-queens/description/)

## Условие

Задача **о n ферзях** заключается в размещении `n` ферзей на шахматной доске `n x n` таким образом, чтобы никакие два ферзя не атаковали друг друга.

Дано целое число `n`. Верните *все различные решения **задачи о n ферзях***. Ответ можно вернуть в **любом порядке**.

Каждое решение содержит отдельную конфигурацию доски с расстановкой `n` ферзей, где `'Q'` и `'.'` обозначают ферзя и пустую клетку соответственно.

## Примеры

**Пример 1:**

![Пример 1](https://assets.leetcode.com/uploads/2020/11/13/queens.jpg)

```text
Input: n = 4
Output: [[".Q..","...Q","Q...","..Q."],["..Q.","Q...","...Q",".Q.."]]
Explanation: существуют два различных решения задачи о 4 ферзях, как показано выше.
```

**Пример 2:**

```text
Input: n = 1
Output: [["Q"]]
```

## Ограничения

- `1 ≤ n ≤ 9`
