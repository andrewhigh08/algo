# 312. Burst Balloons

**Лопнуть шары** · 🔴 Hard · 2-D Dynamic Programming · [LeetCode](https://leetcode.com/problems/burst-balloons/description/)

## Условие

Дано `n` воздушных шаров с индексами от `0` до `n - 1`. На каждом шаре нарисовано число, эти числа заданы массивом `nums`. Нужно лопнуть все шары.

Если лопнуть `i`-й шар, вы получите `nums[i - 1] * nums[i] * nums[i + 1]` монет. Если `i - 1` или `i + 1` выходит за границы массива, считайте, что там находится шар с нарисованной на нём `1`.

Верните *максимальное количество монет, которое можно собрать, если лопать шары с умом*.

## Примеры

**Пример 1:**

```text
Input: nums = [3,1,5,8]
Output: 167
Explanation:
nums = [3,1,5,8] --> [3,5,8] --> [3,8] --> [8] --> []
coins =  3*1*5    +   3*5*8   +  1*3*8  + 1*8*1 = 167
```

**Пример 2:**

```text
Input: nums = [1,5]
Output: 10
```

## Ограничения

- `n == nums.length`
- `1 ≤ n ≤ 300`
- `0 ≤ nums[i] ≤ 100`
