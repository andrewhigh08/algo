# 25. Reverse Nodes in k-Group

**Перевернуть узлы в k-группах** · 🔴 Hard · Linked List · [LeetCode](https://leetcode.com/problems/reverse-nodes-in-k-group/description/)

## Условие

Дана голова `head` связного списка. Переверните узлы списка группами по `k` и верните *изменённый список*.

`k` — положительное целое число, которое меньше или равно длине связного списка. Если количество узлов не кратно `k`, то последние узлы, не вошедшие ни в одну группу, должны остаться как есть.

Изменять значения в узлах списка нельзя. Менять можно только сами узлы.

## Примеры

**Пример 1:**

![Пример 1](https://assets.leetcode.com/uploads/2020/10/03/reverse_ex1.jpg)

```text
Input: head = [1,2,3,4,5], k = 2
Output: [2,1,4,3,5]
```

**Пример 2:**

![Пример 2](https://assets.leetcode.com/uploads/2020/10/03/reverse_ex2.jpg)

```text
Input: head = [1,2,3,4,5], k = 3
Output: [3,2,1,4,5]
```

## Ограничения

- Количество узлов в списке равно `n`.
- `1 ≤ k ≤ n ≤ 5000`
- `0 ≤ Node.val ≤ 1000`
