# 778. Swim in Rising Water

**Плавание в поднимающейся воде** · 🔴 Hard · Advanced Graphs · [LeetCode](https://leetcode.com/problems/swim-in-rising-water/description/)

## Условие

Дана целочисленная матрица `grid` размером `n x n`, где каждое значение `grid[i][j]` — высота в точке `(i, j)`.

Начинается дождь, и вода постепенно поднимается. В момент времени `t` уровень воды равен `t`: **любая** клетка с высотой не больше `t` затоплена или достижима.

Переплыть из клетки в соседнюю по одному из 4 направлений можно тогда и только тогда, когда высота каждой из двух клеток не превышает `t`. Любое расстояние проплывается мгновенно. Разумеется, во время плавания нельзя выходить за границы сетки.

Верните *минимальное время, за которое можно добраться до правой нижней клетки* `(n - 1, n - 1)`, *если начать с левой верхней клетки* `(0, 0)`.

## Примеры

**Пример 1:**

![Пример 1](https://assets.leetcode.com/uploads/2021/06/29/swim1-grid.jpg)

```text
Input: grid = [[0,2],[1,3]]
Output: 3
Explanation:
В момент времени 0 вы находитесь в клетке (0, 0).
Никуда переместиться нельзя, потому что у всех соседних по 4 направлениям клеток высота больше t = 0.
До клетки (1, 1) нельзя добраться раньше момента 3.
Когда глубина воды равна 3, можно плыть куда угодно внутри сетки.
```

**Пример 2:**

![Пример 2](https://assets.leetcode.com/uploads/2021/06/29/swim2-grid-1.jpg)

```text
Input: grid = [[0,1,2,3,4],[24,23,22,21,5],[12,13,14,15,16],[11,17,18,19,20],[10,9,8,7,6]]
Output: 16
Explanation: итоговый маршрут показан на рисунке.
Нужно дождаться момента 16, чтобы клетки (0, 0) и (4, 4) оказались соединены.
```

## Ограничения

- `n == grid.length`
- `n == grid[i].length`
- `1 ≤ n ≤ 50`
- `0 ≤ grid[i][j] < n²`
- Все значения `grid[i][j]` **уникальны**.
