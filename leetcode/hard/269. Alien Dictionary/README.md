# 269. Alien Dictionary

**Инопланетный словарь** · 🔴 Hard · Advanced Graphs · [LeetCode 🔒](https://leetcode.com/problems/alien-dictionary/description/) · [LintCode 892](https://www.lintcode.com/problem/892/)

## Условие

Существует новый инопланетный язык, который использует английский алфавит. Однако порядок букв в нём вам неизвестен.

Дан список строк `words` из словаря инопланетного языка. Утверждается, что строки в `words` **отсортированы лексикографически** по правилам этого нового языка.

Если это утверждение неверно и такой порядок строк в `words` не может соответствовать никакому порядку букв, верните `""`.

Иначе верните *строку из уникальных букв нового инопланетного языка, отсортированных в* ***лексикографически возрастающем порядке*** *по правилам нового языка*. Если решений несколько, верните ***любое из них***.

**Примечание:** строка `s` **лексикографически меньше** строки `t`, если в первой позиции, где они различаются, буква из `s` идёт в инопланетном языке раньше буквы из `t`. Если первые `min(s.length, t.length)` букв совпадают, то `s` меньше тогда и только тогда, когда `s.length < t.length`.

## Примеры

**Пример 1:**

```text
Input: words = ["wrt","wrf","er","ett","rftt"]
Output: "wertf"
```

**Пример 2:**

```text
Input: words = ["z","x"]
Output: "zx"
```

**Пример 3:**

```text
Input: words = ["z","x","z"]
Output: ""
Explanation: порядок некорректен, поэтому возвращаем "".
```

## Ограничения

- `1 ≤ words.length ≤ 100`
- `1 ≤ words[i].length ≤ 100`
- `words[i]` состоит только из строчных английских букв.
